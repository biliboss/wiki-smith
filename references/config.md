# Config: `.wiki/wiki.config`

One optional file per repo, `KEY=value` lines. It is plain sh (the scripts `source` it) and `lint.py` parses the same lines (no expansion; single or double quotes around a value are removed). Without it, the defaults below apply. Anything you leave out keeps its default.

| Key | Default | Meaning |
|---|---|---|
| `WIKI_LANG` | `en` | Language of `lint.py` types and messages: `en`, or `pt-BR` (the original Portuguese tool's output, type names included) |
| `DIARY_DIR` | `journal` | The diary folder, directly under the wiki |
| `INBOX` | `inbox.md` | The diary's door page |
| `INDEX` | `index.md` | The index page |
| `MAIN_BRANCH` | `main` | The branch `sync.sh` publishes to |
| `FOOTER_PREFIX` | `Map:` | Start of the footer line; also the label in the day index |
| `HISTORY_HEADING` | `## History` | The page-history section heading |
| `CREATED_KEY` / `UPDATED_KEY` | `created` / `updated` | The frontmatter keys |
| `NO_TIME_PREFIX` | `no-time` | Prefix of old notes with no time |
| `DAY_TITLE` | `Journal of` | The day index title is `# <DAY_TITLE> YYYY-MM-DD` |
| `PREV_LABEL` / `NEXT_LABEL` | `Previous day` / `Next day` | Labels in the day index map line |
| `GEN_NOTE` | ``Generated index (scripts/day-index.sh); do not edit. Each note is a file in `%s/`.`` | The sentence under the day title; `%s` is the day |
| `CMD_DAY_INDEX` / `CMD_DATES` | `scripts/day-index.sh` / `scripts/dates.sh` | Only for lint messages: the command to regenerate |

The day index is generated by `day-index.sh` and checked by `lint.py` against the same values, so change `DAY_TITLE`, `PREV_LABEL`, `NEXT_LABEL`, `FOOTER_PREFIX`, `GEN_NOTE` only together with a run of `day-index.sh` (it rewrites every index).

Where the config is found: `-c FILE`, else `$WIKI_CONFIG`, else `<wiki>/wiki.config`. The wiki folder: `-w DIR`, else `$WIKI_DIR`, else `./.wiki`, else `<git root>/.wiki`.

Presets: [templates/wiki.config.example](../templates/wiki.config.example) (the defaults, commented) and [templates/wiki.config.pt-BR](../templates/wiki.config.pt-BR) (a Portuguese wiki: `diario/`, `Mapa:`, `## Histórico`, `criado`/`atualizado`).
