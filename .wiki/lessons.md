# Lessons

One line per lesson from a real wiki-smith run: `- YYYY-MM-DD — <rule> — <why>`. Append only. When a lesson repeats or changes the procedure, move it into [SKILL.md](../SKILL.md), bump the [version](../CHANGELOG.md), and add `→ promoted in x.y.z` to the end of its line. Don't delete lines.

- 2026-11-03 — In `sh`, never put a `case` with `)` patterns inside `$( ... )`, and never a bracket of accented letters under `LC_ALL=C` — macOS `/bin/sh` rejects the first, and the second splits UTF-8 letters into bytes (found porting the scripts). → promoted in 0.1.0 (scripts)
- 2026-11-03 — Compare a port with the original on a real wiki and on a deliberately broken copy, sorted — file listing order differs between tools, so unsorted output looks like a mismatch. → promoted in 0.1.0 (lint.py sorts its output)
- 2026-11-03 — Parse SKILL.md frontmatter with a real YAML parser (and run the installer) before publishing; a `: ` inside a plain-scalar description makes the skills CLI skip the whole skill — a regex check had passed it. → promoted in 0.1.0 (description is a folded block)
- 2026-11-03 — A script must never read stdin unless asked (`note.sh -b`): in agent shells and CI stdin is open and never closes, so "read it if it is not a TTY" hangs forever; test scripts with stdin attached to a never-closing pipe. → promoted in 0.1.1 (note.sh)
- 2026-11-03 — Never carry a generated file's diff between checkouts and never carry a shared hand-edited file blind: other sessions' uncommitted lines ride along (a link to a page that exists only in the checkout). Regenerate generated files where you commit, lint before committing, and edit shared files in a fresh worktree (`sync.sh -W`). → promoted in 0.1.1 (sync.sh)
- 2026-11-03 — In a fresh worktree from `origin/<main>`, check that `.wiki/wiki.config` is there before running the scripts — when it is still uncommitted in the main checkout they silently fall back to the English defaults (`journal/`, `Map:`); pass `-c <path>` to the real one.
- 2026-11-03 — Start the body piped into `note.sh` with the text, not a blank line — the script already adds one after the heading, so a leading blank line leaves two.
- 2026-11-03 — Do not send the agent to a worktree for the wiki (`sync.sh -W`): the user works on `main` in the checkout itself, and the extra worktree was not asked for. Commit your own files by path, after reading `git diff`.
